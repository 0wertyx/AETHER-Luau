# AETHER Full — нативная Luau-студия

**Запуск:** откройте `AETHER.rbxlx` в Roblox Studio и нажмите **Play / F5**. Нужен плейтест с игроком: режим **Run** сам по себе не запускает `StarterPlayerScripts`. В игре **RightShift** показывает/скрывает студию, **LeftAlt** переключает плечевой Shift-Lock. Есть экранная кнопка **A / STUDIO**, вкладки прокручиваются, ползунки и перемещение окна поддерживают мышь и касание.

### Установка в своё место

1. В **StarterPlayer → StarterPlayerScripts → Insert from File** вставьте `AetherClient.rbxmx`. Альтернатива: создайте там один **LocalScript** и вставьте весь `AetherFull.client.luau`. Достаточно одного из этих способов.
2. Для серверного хранения вставьте `AetherProfiles.rbxmx` в **ServerScriptService**. Без него доступны все клиентские редакторы и ручной перенос банка через JSON.
3. Для указателя на другого игрока установите **на сервере** его атрибут `AetherShareBearing = true`. Для разрешённой игровой цели добавьте тег `AetherBeacon` к её **BasePart**. Готовое демоместо включает три таких маяка и явно включает передачу направлений для участников демо. Демодекорации не входят в импортируемую клиентскую модель.

### Механики

| Студия | Что можно делать |
| --- | --- |
| Dashboard / HUD | Живое здоровье и MaxHealth, числовая интерполяция, спокойное/предупреждающее/критическое сердцебиение, полный стоп при смерти, оживление, толчок лечения, встряска и отложенная полоса урона. Часы, карточка игрока, док и прицел. Перетаскивание, привязка, масштаб, поворот, прозрачность, индивидуальные градиенты и светящиеся края. |
| Character / Wings / Halos / Neon | Аура, след движения, подсветка тела и PointLight; три силуэта анимированных крыльев, кольцо, двойная орбита и корона. Настройки геометрии, цвета, радуги и скорости. Геометрия видна на манекене редактора и на своём персонаже; частицы и след — в игровом мире. |
| Ambient | 16 атмосфер, включая Dreamcore, Cyberpunk, Anime, Midnight, Aurora, Sunset, Nebula и Moonlight. Цвета неба, туман, bloom, время, яркость, насыщенность, размытие мира и переходы. Переключатель применяет настройки к локальному `Lighting`; при отключении исходные изменённые свойства восстанавливаются. |
| Indicators | 24 нативных силуэта, реальная проекция относительно камеры, затухание, сглаживание вращения, дистанционный масштаб, подписи, два слоя неона, градиенты, пульсация. Переопределения по UserId. Ближние именные метки не рисуются сквозь стены. |
| Cursor / Camera | Шесть встроенных форм указателя и режим Image с Roblox asset ID, hotspot, размер, glow, радуга. Камеры Follow, First Person и Orbit, FOV, высота, радиус, скорость и сглаживание. Shift-Lock освобождает мышь при открытии редактора. |
| Fonts | Поиск среди нативных гарнитур, вес, образец текста, цвет, градиент, обводка, свечение и применение к HUD. Можно указать доступный этому месту Roblox font-family asset ID. |
| Simulator | Отдельные виртуальные HP/MaxHP, урон, лечение и возрождение; до 12 виртуальных игроков, перетаскивание на карте, перестановка и очистка. Команды симулятора не отнимают здоровье у настоящего персонажа. |
| Scripts | Ограниченный интерпретируемый язык HUD, разрешения и события, пользовательские текстовые виджеты; отдельный редактор черновиков Luau с шаблоном, подсветкой, дополнением символов и проверкой скобок. |
| Workshop / Profiles / Diagnostics | Банк именованных ассетов и профилей: захват текущих настроек, применение, дублирование, переименование, удаление, ручной JSON-импорт/экспорт. Встроенные пресеты доступны только для чтения. Ограниченный журнал, информация об источнике и состоянии хранилища. |

Для проверки виджета откройте **Scripts → AETHER Lua**, вставьте **Template**, разрешите `widgets` и `events`, нажмите **Run HUD script**, затем измените виртуальное HP. API: `hud.widget(id,text,x,y)`, `hud.animate(id,"pulse"|"float"|"none")`, `hud.join(a,b)`, `hud.setGlow("heart",0…100)`, `hud.indicator(shape)`, `hud.theme("Violet"|"Ocean"|"Rose")`; события `onHealthChanged(hp,maxHP)` и `onEvent(name,hp)`. Поддерживаются локальные значения, арифметика и `if/elseif/else`. Проверяются права и лимиты текста, выражений и числа виджетов. Импортированный текст сам не запускается. Полноценные произвольные Luau-скрипты компилируются в **Script Editor Roblox Studio**, а не в игровом GUI.

### Профили и ресурсы

В неопубликованном месте и, по умолчанию, в Studio сервер хранит банк только на время сеанса. **Profiles → Export JSON** переносит весь банк; в Workshop экспортируется один выбранный ассет. Скопируйте текст вручную. В опубликованном experience сервер использует собственный `DataStoreService`, ключ отдельный для каждого игрока. Для облачного теста в Studio нужен опубликованный тестовый проект, разрешённый Studio Access to API Services и атрибут `PersistentStudio = true` у серверного скрипта. `UseDataStore = false` принудительно оставляет сеансовое хранение. Об успешной долговременной записи сообщает статус **Saved in Roblox DataStore**. При конфликте версий сначала экспортируйте локальные изменения, затем перезагрузите банк.

Вся игровая логика, GUI и эффекты написаны на Luau. HTTP и внешние сервисы не требуются. Дополнительные картинки и шрифты используются через разрешённые ресурсы Roblox. Локальный PNG/SVG с диска сначала импортируется в Studio. Указатель меняется только в игре; камера и аватарные эффекты работают на клиенте.

### Исходники и сборка

`src/` — модульный оригинал, `src/Start.client.luau` — загрузчик. `default.project.json` описывает расположение модулей. `lune run tools/build` из корня собирает в `dist/` одиночный LocalScript и готовые `.rbxmx`/`.rbxlx` из этих же исходников. Скрипт упаковки также написан на Luau; **Lune не нужен для игры**. `lune run tests/contract` проверяет контракт настроек, пресеты и JSON. Подробности плейтеста — в `VERIFICATION.md`.
