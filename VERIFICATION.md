# Проверка выпуска

Roblox Studio 0.748.0.7481526, Windows x64. Выпуск собирался Lune 0.11.1; синтаксис проверялся официальным `luau-compile` 0.748.

- Контракт: 157 полей настроек, 63 встроенных ассета, 24 формы; проверены схемы всех пресетов, независимость копий профилей, JSON round-trip и отклонение некорректных значений.
- Нативный плейтест: настоящий Studio-сервер и два клиента (`StudioTestService:ExecuteMultiplayerTestAsync`). В одноразовое место помещён выпускной клиентский код и рядом с ним код проверок. В саму поставку приложения тестовые обработчики не включены.
- Успешны **12 групп проверок**: 16 вкладок; клавиатурное открытие/закрытие; крылья, нимб, аура, след и неон на R6; состояния HP, смерть и смена на настоящий R15; разрешение/отзыв направления на второго игрока; применение и восстановление Lighting; Orbit, FOV, Shift-Lock и возврат камеры; виртуальные игроки, 24 формы и изоляция слоя; шрифт, трансформации и анимированный материал; разрешения, события и остановка HUD-программы; Workshop/JSON/серверное хранение; удаление GUI, снятие FX и повторное создание с загрузкой настроек.
- С помощью `VirtualInput` в тестовом клиенте были действительно нажаты RightShift, переключатель материала, ползунок свечения и кнопки сохранения/экспорта/импорта/удаления библиотеки. Значения проверялись в GUI, риге, Lighting и восстановленном банке, а не только по надписям кнопок.
- Проверялся сеансовый серверный банк. Запись в облачный DataStore опубликованной игры, сторонние asset ID и физическое мобильное устройство в этой среде не проверялись.

Тесты `tests/client.luau`, `tests/server.luau` и `tests/runner.luau` работают только в тестовой сборке. Для воспроизведения: `lune run tools/build smoke <существующая-тестовая-папка> AetherFullTest123ABC`. Установите сгенерированный одноимённый `.rbxmx` как временный локальный Studio-плагин, откройте сгенерированное `.rbxlx`; плагин запускает плейтест только для места с этим маркером. Результат в Studio Output: `AETHER_FULL_RESULT <маркер>`. После проверки удалите тестовый плагин. Для обычного запуска используйте `AETHER.rbxlx` без тестового плагина.
